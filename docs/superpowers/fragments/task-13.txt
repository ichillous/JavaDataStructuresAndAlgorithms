| Hopcroft-Karp bipartite matching | O(E sqrt(V)) after an O(E log E) deduplicating sort | O(V + E); iterative augmenting-path search |

(c) SOLUTION-FINDER ENTRIES
- Problem: maximum throughput from a source to a sink through capacity-limited links
  Technique: Dinic maximum flow
  Link: [FlowNetwork](../src/main/java/io/github/ichillous/dsa/graphs/FlowNetwork.java)
- Problem: cheapest set of edges whose removal disconnects s from t (minimum cut)
  Technique: max-flow/min-cut, source side of the final residual graph
  Link: [FlowNetwork](../src/main/java/io/github/ichillous/dsa/graphs/FlowNetwork.java)
- Problem: assign each worker at most one task (maximum bipartite matching)
  Technique: Hopcroft-Karp
  Link: [BipartiteMatching](../src/main/java/io/github/ichillous/dsa/graphs/BipartiteMatching.java)
