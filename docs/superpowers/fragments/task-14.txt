(c) SOLUTION-FINDER entries (docs/solution-finder.md)

- Problem heading: "Lowest common ancestor, distance or k-th ancestor in a tree"
  Technique: binary lifting over a BFS-rooted tree (ancestor table, O(log V) per query).
  Repo link: [LowestCommonAncestor](../src/main/java/io/github/ichillous/dsa/graphs/LowestCommonAncestor.java) and lesson [Tree queries](../algorithms/graph/tree-queries.md)
- Problem heading: "Longest path (diameter) of a tree"
  Technique: double BFS (farthest vertex from any start, then farthest from that vertex).
  Repo link: [TreeAlgorithms](../src/main/java/io/github/ichillous/dsa/graphs/TreeAlgorithms.java) and lesson [Tree queries](../algorithms/graph/tree-queries.md)
