(c) SOLUTION-FINDER ENTRIES
Link to write for each: [Selection](../src/main/java/io/github/ichillous/dsa/algorithms/Selection.java), lesson [selection](../algorithms/searching/selection.md)

- Problem heading: "Find the k-th smallest element (median, percentile) of an unsorted array"
  Technique: Quickselect with median-of-three pivot, three-way partition and a median-of-medians fallback (introselect): Selection.kthSmallest
- Problem heading: "Return the k smallest or top-k items, keeping ties in original order"
  Technique: Bounded max-heap of size k with an arrival-order tie-break: Selection.smallestK
- Problem heading: "Merge k sorted lists into one sorted list"
  Technique: K-way merge with a min-heap keyed by value then list index: Selection.mergeSorted
- Problem heading: "Find the element that appears more than n/2 times"
  Technique: Boyer-Moore majority vote plus a verification pass: Selection.majorityElement
