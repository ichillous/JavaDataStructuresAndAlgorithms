JDK STATEMENTS ADDED (checked against the Java SE 17 API pages)
- ArrayList: get/set constant time, add amortized constant time; Arrays.asList returns a fixed-size view that writes through.
- LinkedList: doubly linked, permits null, indexed operations traverse from the nearer end.
- ArrayDeque: prohibits null, likely faster than Stack as a stack and than LinkedList as a queue.
- Stack: the Deque interface should be used in preference to it.
- ListIterator.add inserts at the cursor; LinkedHashMap access order and removeEldestEntry for LRU use.
- PriorityQueue ties are broken arbitrarily.
