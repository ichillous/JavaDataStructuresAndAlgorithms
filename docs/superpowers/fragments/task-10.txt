| [LazySegmentTree](../src/main/java/io/github/ichillous/dsa/structures/LazySegmentTree.java) | Defensive `long[]` copy; half-open `rangeAdd(from,to,delta)` and exact `rangeSum(from,to)` with lazy pending additions. Empty ranges sum to zero; queries never modify the tree. `rangeAdd` throws `ArithmeticException` and changes nothing exactly when an element would leave `long` range; `rangeSum` throws exactly when the true sum does. Sums and pending additions are exact 128-bit values. | [LazySegmentTreeTest](../src/test/java/io/github/ichillous/dsa/structures/LazySegmentTreeTest.java) |
Append to the paragraph below that table:
A sparse table checks bounds like the segment tree and performs no arithmetic. The lazy segment tree validates bounds before its overflow check, and a rejected range addition leaves every element unchanged.
