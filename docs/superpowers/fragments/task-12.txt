(c) SOLUTION-FINDER ENTRIES
Link target for each: ../src/main/java/io/github/ichillous/dsa/graphs/GraphStructureAlgorithms.java (lessons: algorithms/graph/graph-structure.md, algorithms/graph/minimum-spanning-trees.md)
- Problem: Which vertices disconnect the network if removed? Technique: articulation points, iterative lowlink DFS (GraphStructureAlgorithms.articulationPoints).
- Problem: Can I split the nodes into two groups with no edge inside a group, and if not, show me why? Technique: BFS two-coloring with an odd-cycle witness (bipartition, oddCycle).
- Problem: Does this dependency graph have a cycle, and which one? Technique: iterative DFS with an on-path state (directedCycle).
- Problem: Can I traverse every edge exactly once? Technique: degree check plus Hierholzer (eulerianPath).
- Problem: Cheapest way to connect all nodes, growing outward from a start. Technique: Prim minimum spanning forest with a lazy heap (primMinimumSpanningForest).
