| [BloomFilter](../src/main/java/io/github/ichillous/dsa/structures/BloomFilter.java) | Fixed-size approximate set: `add`, `mightContain`, `insertions`, `estimatedFalsePositiveRate`; `forExpectedInsertions(n, p)` sizes `m = ceil(-n ln p / (ln 2)^2)`, `k = max(1, round(m/n ln 2))`. No false negatives, no deletion; elements with equal `hashCode` are indistinguishable; null rejected. | [BloomFilterTest](../src/test/java/io/github/ichillous/dsa/structures/BloomFilterTest.java) |
| [CountMinSketch](../src/main/java/io/github/ichillous/dsa/structures/CountMinSketch.java) | Approximate frequency table: `add(item[, count])`, `estimate`, `totalCount`; `withErrorBounds(epsilon, delta)` gives `width = ceil(e/epsilon)`, `depth = ceil(ln(1/delta))`. Estimates never undercount; overflow throws `ArithmeticException` and leaves the sketch unchanged; negative counts rejected. | [CountMinSketchTest](../src/test/java/io/github/ichillous/dsa/structures/CountMinSketchTest.java) |

| `CountMinSketch` add/estimate | O(depth) worst | O(width x depth) stored longs; O(1) additional; overestimates only, within `epsilon x total` with probability `1 - delta` |
