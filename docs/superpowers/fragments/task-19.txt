(c) SOLUTION-FINDER entries (lesson: algorithms/math/number-theory.md)

- Problem heading: "Find the largest common divisor, or Bezout coefficients, of two integers"
  Technique: Euclidean algorithm and extended Euclid. Repo link: [NumberTheory](../src/main/java/io/github/ichillous/dsa/algorithms/NumberTheory.java)
  with lesson [number theory](../algorithms/math/number-theory.md).
- Problem heading: "Compute a huge power or an inverse modulo m without overflow"
  Technique: square-and-multiply with exact modular multiplication, and extended Euclid for the inverse. Repo link: same source and lesson.
- Problem heading: "Is this 64-bit number prime, or which primes are below n?"
  Technique: deterministic Miller-Rabin for one number, sieve of Eratosthenes for a range. Repo link: same source and lesson.
- Problem heading: "Compute the n-th Fibonacci number modulo m for huge n"
  Technique: 2x2 matrix exponentiation. Repo link: same source and lesson.
